# 未来学习场 · 景山实验学校 × 京西智谷

这是景山实验学校与京西智谷 AI 创新教育项目的 Windows 互动演示包。打开后，可以从第一人称视角探索数字校园，体验课程模拟，了解京西共创与校园创造节。讲解者也可以在页面里替换图片、视频和讲解词，为下一场演示做准备。

## 在 Windows 上开始演示

适用于 **Windows 10 或 11（x64）**。运行包自带 Node.js，下载并解压后即可离线使用图文展示、课程模拟和素材编辑功能。

1. 在仓库首页选择 **Code → Download ZIP**，将整个压缩包解压到有写入权限的文件夹。
2. 打开包含 `启动景山演示.cmd` 的文件夹，双击该脚本。默认浏览器会自动打开本机演示页面。
3. 演示结束后，双击 `停止景山演示.cmd`。仅关闭浏览器时，本机服务仍会继续运行。

启动脚本默认使用 `127.0.0.1:1430`，端口被占用时会依次尝试 1431 至 1440。启动失败时，可查看 `.local/server-error.log`。

## 为下一场演示修改内容

从页面右上角的指南针打开 **设置**，在课程页也可以从顶栏进入。

| 想做什么 | 在哪里操作 | 如何保存或分享 |
| --- | --- | --- |
| 替换图片或视频 | 在 **图片与演示** 中选择栏目和文件，预览裁切效果 | 点击 **保存到展示**。可导出 `.jingshan-media` 素材包供同事导入 |
| 修改讲解词 | 在 **文字内容** 中编辑原文或添加补充条目 | 点击 **保存文字**。可导出 `.jingshan-text` 文字包供同事导入 |

已保存的设置和替换素材位于 `user-data/`，重启后仍会生效。刷新页面前请先保存草稿。支持的文件格式、大小限制和恢复操作见[使用说明](./使用说明.txt)。

### 启用小景与瓦力的 AI 对话（可选）

在联网状态下，双击 `配置小景对话.cmd`，按提示输入自己的 DeepSeek API 密钥，再刷新演示页面。小景与瓦力共用这项配置。密钥由 Windows 加密保存在当前电脑的 `.local/` 目录中。每位协作者在自己的电脑上配置即可。

## 参与协作

接受仓库邀请后，可克隆项目并创建自己的工作分支。

```sh
git clone https://github.com/netshells1/jingshan-future-learning.git
cd jingshan-future-learning
git switch -c update-course-content
```

| 要维护的内容 | 文件位置 |
| --- | --- |
| 讲解内容与素材位置的默认配置 | [shared/](./shared/) |
| 通过展示设置保存的文字、素材和显示设置 | [user-data/](./user-data/) |
| 本地服务、内容读写和模型对话 | [server/](./server/) |
| Windows 启动、停止和密钥配置 | 根目录的 `.cmd` 与 `.ps1` 脚本 |
| 已构建的前端页面、演示文档和静态素材 | [dist/](./dist/) |

当前仓库发布的是一键运行包，原始前端工程未随包提供。修改完成后，用启动脚本检查受影响的页面或功能，将工作分支推送到 GitHub，再向 `main` 发起 Pull Request。提交展示内容时，请一并提交设置引用的新素材。

第三方组件许可与素材来源见 [licenses/](./licenses/)，随包运行时的许可见 [runtime/LICENSE](./runtime/LICENSE)。
