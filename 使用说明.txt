Windows 免安装一键运行包

开始演示
1. 将 ZIP 完整解压到一个允许写入的文件夹，不要在压缩软件内直接打开。
2. 双击“启动景山演示.cmd”。默认浏览器会打开本机演示页面。
3. 关闭浏览器后服务仍在本机运行。演示结束双击“停止景山演示.cmd”。
4. 重复双击启动会复用本目录的服务。1430 被占用时会自动尝试 1431—1440，
   不会停止其他应用。端口全部不可用时会显示中文提示。

无需安装 Node.js、npm 或开发工具。运行时已随包提供。
本包通过本地服务在浏览器中打开网页，不是桌面应用。
适用于 Windows 10/11 64 位电脑，推荐使用已安装的 Microsoft Edge 或 Chrome。
请保留 runtime、dist、server、shared、user-data 以及所有启动脚本的相对位置。
图文展示、课程模拟与素材更换可离线使用；小景与瓦力的模型对话需要联网。

更换图片和视频
点击右上角指南针里的“设置”，在“图片与演示”中按栏目选择文件。
课程页顶栏也有设置入口。当前共有 87 个独立媒体位置可维护。
支持 PNG、JPEG、WebP、GIF 图片和 MP4、WebM 视频，单个文件最大 60 MiB。
可选择“完整展示，保留留白”或“填满画面，允许裁切”，调整主体位置，
也可点击“恢复原素材”并确认，重新使用默认图片或演示。
保存后会即时用于页面；刷新、关闭或重新启动浏览器后仍然保留。
替换后的素材保存在 user-data，配置在 user-data\media-settings.json。
请不要手工改动其中的文件名或设置。恢复默认后旧素材可能仍保留在磁盘，
以免误删；页面与导出包只使用当前生效的素材。

移动、备份与导入
可以复制整个解压文件夹到其他电脑，当前替换素材一并保留。
也可在“图片与演示”中导出 .jingshan-media 素材包，在另一份演示中导入。
导入会更新包内对应位置，其他已保存素材保留。
素材包最大 160 MiB，解压后最大 250 MiB；过大的视频请先压缩。
导出的素材包仅含当前替换素材与显示设置，不含模型密钥。
若素材设置损坏，页面会提供“从素材包恢复”入口。确认后，程序先校验整个
素材包，将损坏配置另存为 user-data\media-settings.corrupt-时间.json 备份，
再恢复包内素材；无效素材包不会覆盖现有配置。正常导入仍保留其他素材位置。

修改文字
在“展示设置”的“文字内容”中按栏目修改文字，可删除原文或添加补充条目。
文字覆盖 21 页主讲解和 21 个课程入口，共 42 个栏目、495 个原文字段。
将字段留空可隐藏该段内容；“恢复本页默认”会恢复原有文字并移除补充条目。
每个栏目最多添加 8 个条目，标题最多 80 字，正文最多 600 字。
文字保存到 user-data\text-settings.json，刷新或重新启动后仍会保留。
可以导出 .jingshan-text 文字包并在另一份演示中导入（最大 1 MiB）。
导入会更新包内栏目，其他已修改栏目保留；内容按纯文字显示，不执行 HTML。
整个解压文件夹转移时，文字修改会与素材一起保留。
文字编辑修改网页中的介绍，不会改动课程程序或模型的基础项目知识。

草稿与保存
图片预览和文字草稿只在当前页面会话中暂存；切换栏目、课程或关闭设置再打开，
仍可继续编辑。刷新页面或关闭浏览器窗口后，未保存草稿会丢失。
请点击“保存到展示”或“保存文字”后再离开；导出包仅包含已经保存的内容。

可选：配置小景对话
双击“配置小景对话.cmd”，按照提示输入你自己的 DeepSeek API 密钥。
输入内容不会显示；程序以当前 Windows 用户的 DPAPI 加密方式保存到
.local\deepseek-key.dpapi，不将密钥写入网页或源码。
配置后刷新页面即可使用。不配置也可以正常进行图文展示与互动演示。
同一配置也用于瓦力的自然对话；瓦力会接着最近对话和任务状态回应。
密钥与当前电脑、Windows 用户绑定，换电脑或换用户后需要重新配置。
向其他人交付时，请使用正式生成的干净运行包，或先移除整个 .local 文件夹；
不要传递 .local 中的个人配置。关闭服务后再移动文件夹。

运行与故障排查
页面只有在启动本地服务后才能正常使用。请通过启动脚本打开，不要双击 dist\index.html。
若提示文件不完整，请重新解压 ZIP；若无法保存素材，请放到有写入权限的目录。
启动状态和日志保存在 .local，可查看 server-error.log 中的启动提示。
“停止景山演示.cmd”只停止本目录记录且身份匹配的进程。
此服务只监听本机 127.0.0.1，不需要开放防火墙或外网端口。

运行时与许可
runtime\node.exe：随包携带的 Node.js Windows x64 运行时。
runtime\LICENSE：Node.js 的完整许可及所含第三方组件声明，请保留。
licenses 目录：页面使用的 React、React DOM、Scheduler、Three.js 许可。
附带素材来源说明保存在 licenses\media 中；许可文件属于交付包的一部分。
